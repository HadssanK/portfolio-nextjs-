A full-featured e-commerce platform for disposable food packaging with custom product configuration, bulk ordering, and strong SEO using SSR.

**Details:**
Disposable Bazaar is a production-ready e-commerce solution built with Next.js and React to sell disposable food packaging products to retail and bulk customers. It supports complex product variants, custom packaging uploads, and advanced cart and checkout functionality.

**Key Features:**
- Full e-commerce system with retail and bulk ordering
- Advanced product variants including pack sizes, colors, lids, and options
- Custom packaging upload system for PDF, AI, PSD, and CDR files
- Cart management with localStorage persistence
- Separate bundle handling and product bundling
- Secure checkout flow with delivery area and shipping calculation
- Invoice generation and download
- Full-text search with filters and pagination
- Blog system with categories and pagination
- Google OAuth and email/password authentication
- Wishlist system with add/remove capability
- Interactive UI with animations and real-time feedback
- SEO optimization using SSR, metadata, JSON-LD, and Open Graph
- REST API integration with public and protected endpoints

**Tech Stack:** Next.js, React, Tailwind CSS, Axios, Swiper, AOS, Framer Motion, React Toastify, Google OAuth, React Leaflet, HTML2Canvas, JS Confetti, UUID
